# Project Documentation Rules (Non-Obvious Only)

- `example.txt` (repo root) is the original textbook excerpt and is git-ignored; `examples/textbook.os` is the tracked copy used by tests.
- `vm-config.yaml` is git-ignored and generated by `vm config`; the authoritative defaults live in `src/vm/config.py:DEFAULTS`, not in the YAML file.
- The package is named `oslearn-vm` but the import package and CLI are both `vm`; `src/vm/` is a src-layout package built by hatchling.
- `README.md` is the user-facing language reference; `AGENTS.md` and `.roo/rules-*/` are agent-facing and intentionally omit anything derivable from the code.
- "lenient mode" is a documented feature, not a bug: unrecognised statements are skipped with a warning so textbook pseudo-code runs.
